# 🪚 단면도 규칙 마스터

기계·기초 제도 수업용 **단면도 학습·평가 도구**입니다. 설치·인터넷 없이 브라우저(휴대폰 포함)에서 바로 실행되며, [도면읽기 마스터](https://hongyul67-cpu.github.io/domyeon-master/)·[투상도 마스터](https://hongyul67-cpu.github.io/tusang-master/)와 같은 시리즈입니다.

## 🎮 플레이하기
- **온라인**: https://hongyul67-cpu.github.io/danmyeon-master/
- **오프라인**: `index.html`을 브라우저로 열기

## 구성
| 항목 | 내용 |
|------|------|
| 🖥️ **수업 모드** | **칠판·프로젝터용 큰 글씨 슬라이드 13장** · 발문(함께 생각해보기) · 즉석 퀴즈 3문항 · ←/→·스페이스(프레젠터 리모컨)로 넘김 · F 전체화면 |
| 📖 배우기 | 단면도를 그리는 이유 · 종류 5가지 · 해칭 규칙 · 절단선 · 단면하지 않는 부품 |
| 🪚 모드 1 | 단면도 종류 판별(온단면·한쪽단면·부분단면·회전도시·계단단면) |
| 📏 모드 2 | 해칭 45°·인접 부품 구분·절단선과 화살표 규칙 |
| 🚫 모드 3 | 길이 방향으로 단면하지 않는 부품(축·키·볼트·리브·기어이…) |
| 🏁 종합 점검 | 세 영역 혼합 12문제 |

## 특징
- 선택 후 **제출** 방식(실수 클릭 방지), 파티클·클리어 배너 등 연출(fx.js)
- 교사가 [결과수집 링크](https://hongyul67-cpu.github.io/links/link-builder.html)로 열면 결과를 구글시트로 제출(collector.js) — 시트 탭 `단면도 규칙 마스터`
- 활용: **수업 중 설명(수업 모드)** · 학생 자습(배우기) · 학습 확인(제출)

## 수업 중 사용법
1. 허브에서 **🖥️ 수업 모드** → **F**로 전체화면
2. **→ / 스페이스**로 넘기며 설명 (프레젠터 리모컨도 동작)
3. 슬라이드마다 **Q**를 누르면 발문("함께 생각해보기")이 뜹니다 — 학생에게 먼저 질문하고 공개하세요
4. 10~12번 **즉석 퀴즈**: 학생들이 손을 들거나 답하게 한 뒤 **Q**로 정답 공개
5. 수업 후 **Esc** → 모드 1~3 또는 종합 점검으로 학생 각자 풀고 제출

## 시리즈 흐름
선의 종류 → **투상도** → **단면도** → 치수·기계요소 순으로 이어서 쓰면 좋습니다.
(3D로 단면 원리를 체험하려면 [단면도 익스플로러](https://hongyul67-cpu.github.io/section-view-explorer/)와 함께)
